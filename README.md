## Project Overview

*Note: The project plan, including the abstract and objectives described below, was authored by my advisor, Prof. Dr. Nina S. T. Hirata.*

### Abstract
Cervical cancer screening has increasingly benefited from the digitization of liquid-based cytology slides via Whole Slide Imaging (WSI), paving the way for computer-assisted screening. In the context of developing computational methods to assist this diagnostic analysis process, the classification of individual cells regarding possible atypias is a fundamental task. This project aims to study and evaluate deep learning-based methods for the classification of cervical cells, aiming for both diagnostic efficacy and computational efficiency.

### Objectives
The main objective of this work is to study and evaluate deep learning-based methods for cell classification in Whole Slide Imaging (WSI) of liquid-based cervical cytology, striving for diagnostic efficacy and computational efficiency. 

This project is part of a Thematic Project collaboration with Prof. Dr. Michelle Discacciati (Faculty of Pharmaceutical Sciences/University Hospital - USP), who will provide scientific backing and specialized support in the domain of clinical application.
